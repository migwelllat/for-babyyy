PEONIES FOR YOU — GitHub Pages mini-site

FILES
- index.html: the entire website
- music.mp3: the music you provided (used as background music)
- photos/photo1.jpg and photos/photo2.jpg: replace these with her pictures

ADD PHOTOS
1. Choose two pictures and crop them portrait-style (3:4 looks best).
2. Put them inside the photos folder.
3. Name them exactly photo1.jpg and photo2.jpg. If your pictures are PNG, either convert them to JPG or update the image paths in index.html to .png.
4. You can change the captions by editing “a favorite memory” and “my pretty girl” in index.html.

CHANGE THE MESSAGE
Open index.html in a text editor and search for “Hii Babyyy!” or “Love youuu!!”. Edit the text in the intro-copy and message-card sections. The opening greeting appears in the heading and again in the note card.

CHANGE THE MUSIC
Replace music.mp3 with your own audio file, keeping the exact filename. For a different filename, update src="music.mp3" in index.html. Music is attempted after the envelope opens; if the browser blocks playback, the music button lets the visitor start it manually.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new repository, e.g. peonies-for-you.
2. Upload index.html, music.mp3, README.txt, and the photos folder (with photo1.jpg and photo2.jpg once you've added them). Keep the same folder structure.
3. Open the repository → Settings → Pages.
4. Under “Build and deployment”, select “Deploy from a branch”.
5. Select branch “main” and folder “/ (root)”, then Save.
6. Wait a minute or two. GitHub will show the website URL in Settings → Pages, usually https://YOUR-USERNAME.github.io/peonies-for-you/.
7. Open that URL on your iPhone to test it. If you change files later, allow a little time for the published page to update.

IPHONE NOTE
The layout uses a mobile-first design and safe-area spacing for modern iPhones. The uploaded MP3 may be large, so it can take a moment to load on mobile data. Autoplay with sound is often blocked by browsers; tapping the envelope is the user gesture that starts playback, and the toggle remains available.
